# SmartWallet UI

Ce dossier contient l'interface utilisateur React + TypeScript pour SmartWallet.

Résumé des changements récents
- Page d'accueil `HomePage` (nouveau) avec : Header, Hero (carte 3D flottante), `Features` et `HowItWorks`.
- Composants ajoutés : `src/components/Features.tsx`, `src/components/HowItWorks.tsx`.

Navigation
- `/` : Page d'accueil
- `/login` : Page de connexion
- `/register` : Page d'inscription
- `/dashboard` : Tableau de bord (protégé)

Style
- Tailwind CSS (mode sombre). Les composants utilisent des classes Tailwind et le style glassmorphism.
- Icônes : `lucide-react` (Wallet, Shield, Zap, BarChart3, ArrowRight, Check)

Scripts utiles
- Dev : `npm run dev`
- Build : `npm run build`
- Preview : `npm run preview`

Comment lancer localement

1. Installer les dépendances depuis le répertoire `smart-wallet-ui` :

```powershell
cd smart-wallet-ui
npm install
```

2. Lancer le serveur de développement :

```powershell
npm run dev
```

3. Ouvrir `http://localhost:5173` (ou l'URL indiquée par Vite).

Notes
- Le build a révélé une erreur TypeScript préexistante dans `src/pages/ProfilePage.tsx` (assignation d'une valeur `string | undefined` sur un prop qui attend `string`). Ce fichier n'a pas été modifié par ce README.

Si vous voulez, je peux corriger l'erreur TypeScript et exécuter à nouveau `npm run build`.
